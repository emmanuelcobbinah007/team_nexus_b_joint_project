Why order matters

Penalty = ∑ (cumulative travel time to reach each case) ÷ its triage level — an urgent case has almost no tolerance for delay, so its wait counts almost fully; a routine case tolerates the same wait far better. Lower total penalty is better.

About this DP

Builds the full dp[items][capacity] table bottom-up, then backtracks from dp[n][capacity] to recover which items were actually chosen — not just the total value. See docs/traces/trace_knapsack.md for a fully worked, hand-verified example.
